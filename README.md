# Evaluasi Pekan 5 — Kedai Senja

## Deskripsi
Proyek JavaScript untuk mencatat data kedai, menghitung transaksi kasir, dan membuat laporan harian.

## Teknologi
- HTML5
- JavaScript
- Git
- GitHub

## Cara Menjalankan
1. Buka file `index.html` menggunakan browser.
2. Tekan `F12`.
3. Pilih tab Console untuk melihat hasil JavaScript.
